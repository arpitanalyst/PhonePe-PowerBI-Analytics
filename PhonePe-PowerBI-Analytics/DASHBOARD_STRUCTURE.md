# Dashboard Structure

| Page | Main KPI / Measure | Key Analysis |
|---|---|---|
| Home | Transaction amount, successful transactions, total transactions, failed transactions | Reasons, monthly trends |
| Insurance | Total premium | Status, monthly premium, reasons, insurance type |
| Loans | Total loan amount | Status, monthly trend, reasons, loan type |
| Money Transfer | Total transfer amount | Status, monthly trend, reasons, transfer type |
| Recharge & Bills | Total amount | Status, monthly trend, reasons, recharge type |

## Model Tables Identified

- `All_Transactions`
- `All_Users`
- `Insurance`
- `Loans`
- `Money_Transfer`
- `Recharge_Bills`

## Main Fields Referenced by the Dashboard

- Date
- Amount
- Transaction_ID
- Payment_Status
- Reason
- Premium
- Insurance_Type
- Loan_Amount
- Loan_Type
- Transfer_Type
- Recharge_Type

## Visual Types
The report uses Power BI:
- KPI/card visuals
- Pie charts
- Area charts
- Line charts
- Column/bar charts
- Date slicers
- Images and navigation elements
